# ChangeLog Timeline Component

A simple and responsive **ChangeLog / Timeline UI component** built with **HTML and CSS**.  
This component visually displays product updates, releases, and improvements in a clear timeline format.

## 📌 Features

- Timeline-based layout for chronological updates
- Clean and minimal UI
- Pure HTML & CSS (no JavaScript required)

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
